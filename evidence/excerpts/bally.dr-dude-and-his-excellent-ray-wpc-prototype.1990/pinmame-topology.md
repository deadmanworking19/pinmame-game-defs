# WPC Alpha-1 controller and physical edition

Pinned PinMAME 46e1a01a0f73dc5ce163d98db1ae435883ecc450, src/wpc/sims/wpc/full/dd_wpc.c lines 397-465: dd_p06 and dd_p7 are declared clones of dd_l2 but initialize GEN_WPCALPHA_1, two CORE_SEG16R 16-character displays at starts 0 and 20, FLIP_SWNO(82, 81), no custom columns/lamps/solenoids, and zero matrix inversion masks. Its standard switch conversion is WPC decimal column/row, not System 11 sequential numbering.

src/wpc/wpc.c:643-659 returns the matrix directly at WPC_SWROWREAD, the dedicated cabinet column at WPC_SWCOINDOOR, and the complemented flipper column at WPC_FLIPPERS. Zero matrix inversion plus ROM active1 establishes normally-open matrix contacts; it does not by itself establish every flipper-column contact construction. core_updateSw copies 112 (right button) to81 and 114 (left button) to82, and synthesizes 45/46 and 47/48 because FLIP_SOL is absent. Unmasked flipper-column bits can be host-written and the register can read them; this is not proof the prototype firmware or physical cabinet uses them.

src/wpc/wpc.h WPC_COMPORTS calls dedicated 1-4 coin inputs and 5-8 Escape/Down/Up/Enter. Those are emulator keyboard labels, not evidence of this prototype's physical service switches. The retained prototype ROM actually navigates tests with level 5 and advance 6. dd_wpc.c maps the keyboard CoinDoor toggle to swRCoin, so it must not be described as a physical WPC-95 coin-door interlock. Dedicated service inputs 7/8 and coin paths1-4 require further fitment/ROM use evidence.

wpc.c WPC_SOLENOID1..4 publishes1-28; public 29/30 always mirror WPC_GILAMPS bits 5/6 as meaningful virtual J111 GPIO state. Their used availability does not establish a game-specific physical load. Public 32 is constant zero because the state remap has only three bits at 29-31. Pre-Fliptronic GAME ON31 comes from WPC_GILAMPS high bit (wpc.c:505-518); it controls the flipper relay chain. Upper-flipper33-36 and WPC-95-only37-44 do not denote fitted devices on this Alpha-1 game. core_getAllSol forwards simulator output49, which is meaningful virtual manual-plunger release state;50 is a gap. wpc.c initializes five G.I. channels 0-4, which the prototype's service cycle individually exercises. Neither source nor that generic test label supplies string names or bulb quantities.

The factory WPC replacement sheet proves a physical hardware edition: CPU A-12742-2016, Power Driver A-12697-1, Display Driver A-12739-1, A-12794 display boards, Sound Interface A-13502, transformer and cables, bottom arch and selected coils. The WPC solenoid table assigns its own1-28 loads. Its printed A/C relay notes are reused System 11 text, not WPC multiplex proof. Keep its literal blank function cells and unusual connector/transistor entries.

The primary curator visually checked both WPC factory sheets and the retained physical WPC full-playfield photograph IPDB 27661. Its fixed playfield topology agrees with the common Dr. Dude physical assemblies, but that photograph does not measure hidden coil or socket centers. Any copied coordinates are an explicit observed production-table geometry overlay, never a claim that the retained S11 script runs WPC firmware.

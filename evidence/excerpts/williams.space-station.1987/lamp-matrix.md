# Space Station — Lamp-Matrix Table (printed page 52)

Source: `Williams_1987_Space_Station_Operations_Manual_and_Test_Procedures.pdf` (86 pages, SHA-256
`71e3212599e733ed432cdc533190ead6a925ff7a5d62862d7c09897566aaddbc`), PDF page 56 (footer `SPACE STATION
52`). Read from the page's embedded 150 dpi scan rendered at 300 dpi, cropped and enlarged in strips; the
scan has no text layer and the Windows OCR pass was used only to find pages. The page carries the
lamp-matrix wiring drawing at the top and the "SPACE STATION Lamp-Matrix Table" below it. Every cell is
transcribed. In each table cell the lamp number is printed at the lower right and the name above it.

## Matrix wiring drawing (top of page)

A single connector block, printed as a boxed column of arrow-shaped pins at the left edge, with the wire
and column/row label beside each line (no pin numbers are printed). From top to bottom: `Yel/Gry Column
8`, `Yel/Vio Column 7`, `Yel/Blu Column 6`, `Yel/Grn Column 5`, `Yel/Blk Column 4`, `Yel/Orn Column 3`,
`Yel/Red Column 2`, `Yel/Brn Column 1`, then `Red/Brn Row 1`, `Red/Blk Row 2`, `Red/Orn Row 3`, `Red/Yel
Row 4`, `Red/Grn Row 5`, `Red/Blu Row 6`, `Red/Vio Row 7`, `Red/Gry Row 8`.

The drawing is an 8 x 8 grid; each crossing carries a lamp mark labelled with a two-digit lamp number.
Column 1 holds `01` to `08`, column 2 `09` to `16`, column 3 `17` to `24`, column 4 `25` to `32`, column 5
`33` to `40`, column 6 `41` to `48`, column 7 `49`, `49`, `51` to `56` and column 8 `57` to `64`: the row 2
crossing of column 7 is labelled `49` a second time where the table prints `50`. A symbol at the right,
labelled `Column` and `Row` and captioned `Typical Lamp Circuit`, shows a lamp in series with a diode.

## Copies on PDF page 31 (printed "SPACE STATION 27") and PDF page 85

PDF page 31 ("TEST/DIAGNOSTIC PROCEDURES", "LAMP TESTS.") prints the same table after the Single Lamps
text, which reads in part: "Then, the player 3 display shows 04 01, and the player 1 and 2 displays change
to show BON BAL PLYR 1, the name of the lamp currently blinking. Press the Credit button to proceed through
an ascending series of designator numbers (01 through 64), with the player 1 and 2 displays showing the
individual lamp's name." PDF page 85 (Section 3, no folio) prints it again above a copy of the
Switch-Matrix Table. Read cell by cell, all 64 cells and all headers of both copies agree with page 56 in
every printed word and digit, including `Not Used` in cell 41 and the legend. Copies of one table are one
source. The All Lamps paragraph above the page 31 copy says "CPU Board connections at jacks 1J6 (columns)
and 1J7 (rows) are also listed in the table", the reverse of the table itself, whose column headers print
1J7 pins and whose row headers print 1J6 pins.

Normalization: none beyond writing each cell as "name (parenthetical) number" in row-major order, joining
lines printed one under another with a single space, and writing the two-line wire `RED-` / `BRN` as
`RED-BRN`.

Uncertain cells: none.

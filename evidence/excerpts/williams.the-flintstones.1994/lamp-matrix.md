## Lamp Circuit, PDF page 105 (printed page 2-40)

Williams "The Flintstones" (1994), Operations Manual 16-50029-101 (July 1994), file `Williams_1994_The_Flintstones_English_Manual.pdf`. PDF page 105, printed page number `2-40` (Section 2). Table title: "Lamp Circuit" (the lamp matrix: 8 columns x 8 rows).

Layout: the top-left corner cell is split by a diagonal into `COLUMN` (upper right) and `ROW` (lower left). Each column header prints, in order: the column number, the column drive wire colour (two words joined by a hyphen, with a line break after the hyphen), the connector pin, and the transistor. Each row header prints the row wire colour, the connector pin, the transistor, and the row number in the lower-left corner of the header cell. Each of the 64 cells prints the lamp name (several lines) and, in its lower-right corner, the lamp number. In the transcription below, the printed line breaks inside a cell are collapsed to single spaces and the lamp number is given in square brackets. In this scan the quote marks around names print as single ticks (`'C'`); the same marks print as double quotes in the PDF 118 copy (see note).

Notes on the printed layout and apparent misprints:
- The printed lamp numbers follow the pattern tens digit = column, units digit = row (for example column 4, row 6 prints 46). The number sits in the lower-right corner and in several cells overlaps the last text line (63, 64, 23, 43, 58, 27, 85, 86).
- The column connector pins skip J137-4 and print J137-5 for both column 4 and column 5; the row connector pins skip J134-3 (row 3 prints J134-4). These are as printed; no reading was changed. (The PDF 118 and PDF 002 copies print the same.)
- Row 8 wire colour is printed `Red-Gray` here.
- Cell (row 5, column 4) prints `4-Bnk D. Tgt 'R'` with no full stop after `Tgt`; every other 4-Bnk cell prints `D. Tgt.` with a full stop, as printed.
- Cell (row 8, column 2) prints `Pltd 2X` as printed.
- Cell (row 7, column 1) prints `Bedrock Water Buffalo` (the last word reads `Buffalo`).

### Differences between copies

Compared cell by cell: PDF 105 (this page, printed page 2-40), PDF 118 (printed page 3-4, titled `LAMP CIRCUIT` in capitals) and PDF 002 (front matter, no printed folio, titled `Lamp Circuit`).

| Location | PDF 105 | PDF 118 | PDF 002 |
| --- | --- | --- | --- |
| Row 8 wire colour (row header) | Red-Gray | Red-Gray | Red-Grey |
| Quote marks around names (all cells, for example `'C'`) | single ticks as rendered | double quotes as rendered | single ticks as rendered |
| Page title text | Lamp Circuit | LAMP CIRCUIT | Lamp Circuit |

All other cell texts, lamp numbers, drive wires, connectors, transistors and row wires are identical in the three copies. The quote-mark row is a scan/typesetting appearance difference and the only one of that kind; the PDF 118 page also carries a `LAMP MATRIX CIRCUIT` schematic and explanatory text below the table, which this transcription does not cover.

### Uncertain readings

- The lamp-number glyphs printed in the lower-right of every cell in this scan are blurred. Cell (row 5, column 5) `55` and cell (row 6, column 5) `56` are the least distinct (the first looks like `55`/`56`); both were settled from the sharper PDF 118 copy, where they read `55` and `56`.
- The column 5 connector `J137-5` is blurred in this scan (the last digit could pass for `6`); settled as `J137-5` from the sharper PDF 118 copy, which prints `J137-5` for column 5 and `J137-6` for column 6.
- Several other lamp-number digits in the right-hand columns (for example 61, 81, 82, 83, 84, 85, 86, 87, 88) are smeared in this scan; read from the PDF 118 copy and the regular numbering sequence.

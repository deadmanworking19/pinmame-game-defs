## Reading

Item 7, `A-20781-1 16-LED Skull Driver PCB Assy.`, carries the same assembly number as the board
pinned PinMAME's `ss.c` calls "a 16 LED Skull driver board assembly A-20781" of "Prototype 0.1",
"not kept in production build". Item 6, `A-21287-1`, is a 6-Lamp/Flasher Assembly, not the skull
board: an earlier revision of this definition attributed the 16-LED description to `A-21287-1`.
The list has no not-fitted or deleted marking for any item, so it cannot by itself say which
listed assemblies production machines carry; Midway's own development notes
(`development-notes-pile-o-skulls.md`) say the skull LEDs were removed for cost.

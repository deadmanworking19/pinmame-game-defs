- Addressed to "Parts & Service Managers", dated "October 21, 1999": "Harley-Davidson Autotrol Motor 50Hz Interface Kit &
  Installation Instructions".
- "Intermittent operation or jogging of the motorcycle up/down motor in countries using a 50Hz Line Frequency."
- "We have observed in countries using a 50hz line frequency that some motors stutter or operate intermittently. We have
  made an adapter harness that plugs into the existing game harness between the motor connector and the game harness
  connector. This Harness contains a 68 [Ω] 2 Watt Resistor which corrects the intermittent operation of the motor.
  Though only a some games have exhibited these symptoms, we feel it is important to install this harness in all games to
  ensure this potential problem does not occur later."
- Parts: "50Hz Interface Harness 036-5425-01"; "Cable Tie 040-5001-02"; "This Tech. Brief Nº 49 755-6410-00".
- Page 2: "Disconnect (C) & insert the Interface Harness (B) inbetween the two ends of the Motor Harness (D)."; a photo
  caption reads "Note the Cap & Neon Bulb on the Motor Harness Connector".

The complete DIP25 declaration, verbatim:

```text
DIP 25 TWO PLAYER GAME OPTION REMOVED

DIP 25 FREE PLAY ON/OFF
```

The related alpha release describes replacing all four player displays
with seven-digit units, distributing MPU A4 J1-7 to player display pin12
(pin11 for Stern displays), and leaving credits unchanged. Its file list
names STARS103_7X.U2/U6 and a separate Weebly512 image. Its history reaches
v72 with a stack-top correction and says testing was limited to PinMAME.
The pinned driver instead names STARS_72.U2/U6. Those similar names do not
prove identical bytes, so none of these installation or DIP changes is
silently applied to the factory definition or six-digit starsb set. The
untouched full readme and acquisition record remain external.

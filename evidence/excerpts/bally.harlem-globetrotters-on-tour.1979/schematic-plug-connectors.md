# Harlem Globetrotters On Tour - plug connectors sheet: A3, A4 and A5 connector blocks, Table "B" and notes

Transcribed from `Bally_1979_Harlem_Globetrotters_On_Tour_Manual.pdf`, PDF page 43, the plug connectors sheet W-1187-14c, read from 206 dpi and 300 dpi renders of the scan (the sheet is printed rotated). Each block lists the connector pin, the printed function or destination and, in parentheses, the wire number printed beside the pin; a pin with no wire number beside it has none in parentheses. The sheet's own wire colour code reads the wire numbers (below). Transcribed here: every A3 block, the A4 J2, J3 and J4 blocks, every A5 block, Table "B", the wire colour code and the notes. Not transcribed: the A1 display, A2 transformer and A4 J1 and J5 blocks, which this record does not cite.

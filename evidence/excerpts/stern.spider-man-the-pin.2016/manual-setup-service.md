# Setup, service and identity facts

Spider-Man_ThePin_web.pdf, SHA256 `5bfe21f7c3f0a71823ca225612d9514604347c6b2d37978c128954a9b87a49b5`. Read from rendered PDF pages 3, 9-12 and 24; paraphrased factual notes, not a replacement for the manual.

- Page 3 lists four supplied pinballs. This does not mean all six numbered trough positions should start occupied.
- Pages 9-10 describe entering service from the volume menu, using lower flippers to navigate, Start to select and Launch to leave. The diagnostics provide lamp, coil, display, sound, switch and game tests.
- Page 11 describes a three-target-bank test in which the displayed three bits change as targets are pressed and Start resets the bank. The Trough test requires the ball-occupied positions to change and Start fires the ejector; the ball-save-lock test controls right-ramp locking and release. Actual timing, sensor levels and gate topology need the firmware/runtime or a physical inspection.
- Page 12 provides a balls-installed adjustment whose default is four, ball-save timing and a factory-reset choice; settings are not physical measurements.
- Page 24 identifies game model 500-55H8-01 and manual 780-50H8-00. PDF metadata creation time is 2016-10-14, consistent with the independently checked November2016 physical identity.

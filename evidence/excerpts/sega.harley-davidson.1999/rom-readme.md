# Harley-Davidson — Stern Pinball ROM readme

Read from `hdROMreadme.txt`, Stern Pinball's ROM release notes for the game, retained as the Wayback Machine's 2006-05-12
capture of `http://www.sternpinball.com/downloads/hdROMreadme.txt`. Plain text; transcribed in full in file order, with
each release's ROM table as a table and its change list verbatim. The header reads "STERN PINBALL, INC. / (C) COPYRIGHT
1999-2004, STERN PINBALL, INC. / Harley Davidson". The file opens with the 4.00, 3.00 and 3.01 entries and repeats them,
identically, after the 1.08 entry; they are transcribed once, at the end.

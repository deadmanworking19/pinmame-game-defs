# Corvette — Solenoid/Flasher Table

Source: Bally "Corvette" (1994) service manual, PDF page 110 (printed page 2-48), "SOLENOID/FLASHER TABLE", transcribed from the 300 dpi grayscale render `rendered-300/m-110.png`. The same table is reprinted on PDF page 119 (printed 3-5); the comparison is in the last section. Cells were read from magnified crops, never from OCR. Transcribed literally, in print order; `(blank)` marks a printed cell with no content. The table has no rows for solenoid numbers 29-32. Method: manual visual transcription from rendered page crops (not reviewed by a second curator).

Column layout in print order: Sol. No. | Function | Solenoid Type | Voltage Connections (Playfield, Backbox, Cabinet) | Drive Xister | Drive Connections (Playfield, Backbox, Cabinet) | Drive Wire Color | Solenoid Part number / Flashlamp Type (Playfield, Backbox).

Merged cells: for rows 02 and 05 the printed text `SM1-28-900-DC` / `SM1-35-4000-DC` straddles the divider between the Playfield and Backbox part-number columns (one cell spanning both); it is entered once under Playfield and the Backbox cell is marked `(merged)`.

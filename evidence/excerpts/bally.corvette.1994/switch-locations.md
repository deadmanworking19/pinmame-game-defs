# Corvette — Switch Locations

Transcribed from `Bally_1994_Corvette_Manual.pdf`. The `SWITCH LOCATIONS` parts list is printed in a two-column
layout that starts at the bottom of PDF page 108 (printed page `2-46`: left list column F1-28, right list column
26-41; see the note on the column split below) and continues under the playfield drawing at the bottom of PDF page 109
(printed page `2-47`: left list column 42-63, right list column 64-88). The playfield drawing with numbered
balloons occupies the upper part of PDF page 109, under the heading `SWITCH LOCATIONS (continued)`. Read from the
rendered 300 dpi pages, not from the OCR text.

Header of each of the four list columns, as printed: `Item` / `No.` | `Switch Part` / `No.` | `Description`. The
page heading `SWITCH LOCATIONS` is printed above the two columns of page 108 (centred); page 109 repeats the column
headers without that heading. A vertical rule separates the two list columns of each page. `---` is the literal
printed dash string for a blank switch part number. A row whose second line is `(Transistor)`, or that has only a
second part number, is the continuation line of the same item; it is joined to the item's row here with ` / `.

Column split on page 108: left column F1-F8, 11-18, 21-25; right column 26, 27, 28, 31-38, 41. Page 109: left
column 42-48, 51-58, 61-63 and the footnote `*Not Shown`; right column 64-68, 71-78, 81-88.

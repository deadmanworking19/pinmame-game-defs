Keyboard-enabled update writes column 0 and matrix 1-8 (`s11.c:787-794`), while keyboard-disabled direct writes are not overwritten by that path. `core_updateSw` passes NULL without keyboard (`core.c:1872-1873`).

## WPC prototype namespaces and caveat

`wpc.c:187-188,380-381` conversion is decimal column/row, not S11 sequential: matrix `11-18,21-28,31-38,41-48,51-58,61-68,71-78,81-88`; flipper column `111-118`. `dd_wpc.c` declares `FLIP_SWNO(82,81)` and zero inversion mask; therefore lower button input 112 is copied to 81 and 114 to 82 by `core_updateSw`, unlike S11's public 82/84. WPC row reader returns selected matrix direct while its flipper register returns complement (`wpc.c:643-659`); do not infer physical rest state of the flipper column from zero inversion mask. WPC initializes 64 lamps, 50 base solenoid span and 5 dedicated GI outputs `0-4` (`wpc.c:1251-1254,1268-1269`). WPC base lamps use `11-18` through `81-88`; output semantics and unused addresses require prototype-specific physical and runtime evidence. Do not transfer S11 bindings to these two clones.

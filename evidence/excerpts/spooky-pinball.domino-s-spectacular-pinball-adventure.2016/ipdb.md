# IPDB identity: Domino's Spectacular Pinball Adventure

Read from the IPDB machine pages saved on 2026-10-05 by primary Opus 5.5 curator, 2026-10-05.

- IPDB 6418: Standard Edition; about 60 units, production from October 17, 2016.
- IPDB 6586: Limited Edition; 75 units, November 2016; IPDB: exactly the same as the Standard Edition except the backglass art and the LE metal plaque.

MPU: PinHeck System. Model number 00003. Every edition runs the same code update and shares the playfield; IPDB lists the editions' differences as cosmetic or, for The Jetsons' Special Edition, a backbox topper.

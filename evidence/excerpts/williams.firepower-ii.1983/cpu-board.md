**Bottom note:** `NOTE: USE EITHER 5641-09312-00, 5641-09024-00 OR 5641-09371-00`


Revision block A on PDF 22, the other half of drawing D-8342, reads `ITEM No.11 WAS` / `5341-09233-00` and `ITEM No12 WAS` / `5341-09234-00`, dated `10/10/80`, initials `G. H`. The circled A marks on rows 11/12 refer to that revision. C83 is added below row 46's other designations. Row 34 gives quantity 13 for twelve named designations; row 64 gives quantity 13 for twelve named designations and a blank slot. Row 57 says quantity 5 despite naming only 1J1. Row 65's mark is rendered as [star-like mark], followed by 1502-1. Row 39 has overstruck ink: the native raster is best read as 09024, but the penultimate digit remains uncertain; 09029 is not supported. Row 29's prefix reads 5090, and row 55's designation cell is empty, rather than a printed dash.

PDF22-23 assembly shows IC35 diagnostic display, IC34 decoder and no DS1/DS2 footprints. PDF24-25 logic traces IC18 PA4/5/6/7 (pins6/7/8/9) to IC34 A/B/C/D (pins7/1/2/6), then IC35 MAN72A through150-ohm resistors. It draws no switch banks on these nets. IC28/29/37 are DIP resistor packages, not switches. The BOM row and assembly view belong to the same factory drawing, D-8342; they are not independent evidence. The photographed production model 521 CPU board (IPDB photo 50056; physical-photos.md) independently shows the diagnostic display and resistor packs with no visible DS1/DS2 banks. Together with the logic topology, this supports treating F/D banks as generic emulated Master Command entry scaffolding rather than fitted CPU DIP switches. The contradictory BOM row remains visible rather than being silently removed.

Pinned s7.c s7_dips_r exposes bank1/2 nibbles on PA4-7 only while service Enter(-3) is held, inverted (on=0 at the ROM port). The driver registers these generic ports; registration supplies no physical switch connection. Public9-16 correspond F1-8 in increasing emulator bit order,17-24 D1-8; these labels describe transport bits, not factory adjustment numbers or physical switch legends. Sound-board DIP1/2 are separate fitted components in the sound-board assembly/BOM.

# Black Knight 2000 — Lower Playfield Switches (printed 66) and Upper Playfield Switches (printed 72)

Source: `Williams_1989_Black_Knight_2000_Operations_Manual.pdf`, PDF page 70 (printed "Black Knight 66",
Lower Playfield Switches) and PDF page 76 (printed "Black Knight 72", Upper Playfield Lamps above
Upper Playfield Switches). Read from 345 dpi renders of the native ~345 ppi bilevel scan; the PDF
has no text layer. Every list row is transcribed. A cell that is empty in the scan is written
"(blank)". The drawings beside the lists put a circled item number on each switch.

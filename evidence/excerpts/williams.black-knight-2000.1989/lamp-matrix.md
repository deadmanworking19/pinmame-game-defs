# Black Knight 2000 — Lamp-Matrix Table (printed page 68)

Source: `Williams_1989_Black_Knight_2000_Operations_Manual.pdf` (102 pages), PDF page 72 (printed
"Black Knight 68"; the lamp-matrix wiring drawing is printed above the table on the same page).
Read from a 345 dpi render of the native ~345 ppi bilevel scan; the PDF has no text layer. Every
cell is transcribed. A circled digit inside a cell is the table's "Item Identifier" and is written
"(item n)". The unnumbered foldout copy on PDF page 101 prints the same tables; this excerpt reads
the numbered page.

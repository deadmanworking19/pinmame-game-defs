Text printed above the table on the same page (verbatim excerpts): `To locate the wiring associated with a particular
feature lamp, refer to the Lamp-Matrix Table. CPU Board connections at jacks 1J6 (columns) and 1J7 (rows) are also
listed in the table.` The table itself prints 1J7 on the columns and 1J6 on the rows, the reverse of that sentence.

PDF page 65 prints a second copy of this table above a second copy of the switch matrix; compared through its OCR
text, it shows the same cells, transistors, wires and pins.

Uncertainty: the 1J6 row connector skips pin 4 and the 1J7 column connector skips pin 5 (key pins); the table
prints no bulb type per cell, so which cells carry #44 and which #555 bulbs is not stated here.

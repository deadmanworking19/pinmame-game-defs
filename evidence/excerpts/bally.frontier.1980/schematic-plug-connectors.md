# Frontier - plug connectors (W-1187-25c), every module connector the game wires

Source: `Bally_1980_Frontier_Schematic_Diagrams_paginated.pdf`, PDF page 8, the plug-connector sheet marked "FRONTIER", drawing number W-1187-25c, read from the native 300 dpi render and gridded crops of each connector block. Each block is transcribed in full in pin order with the wire number printed on the lead and the name printed against the pin. "N/U" and "KEY" are the page's own; a pin with no wire number drawn is written `(none)`. Abbreviations are kept as printed.

Wire colour code printed on the sheet: 1 red, 2 blue, 3 yellow, 4 green, 5 white, 6 brown, 7 orange, 8 black, 9 gray, 0 no trace (a two-digit wire number is body colour then trace colour).

## Identity and edition boundary

The retained OPDB machine `Gxv3q-MXrBj` names `Avengers the Pin`, marks physicalMachine 1 and records manufacture date 2013-01-01. Independent interactive IPDB machine 6373 names `Avengers The Pin™`, Stern, 2013, as a non-commercial home model. The exact current API record names `Avengers The Pin (1.0.3)`, has flags 0 and no clone parent. This title is a separate physical record; shared theme and the commercial editions' short-name prefixes do not establish hardware compatibility. OPDB's broad display field is identity metadata and is not display transport authority. These facts come from `avscp_103.identity.opdb`, `avscp_103.identity.ipdb` and `avscp_103.catalog.api`.

Every legal converter switch 0-95/101-132, configuration ordinal 1-8, canonical solenoid 1-33/45-48/51-72 and title lamp 1-64 is explicitly represented. These are transport envelopes, not physical device counts. Switches 96-100 and solenoid 34-44/49-50 are not independent canonical devices. Canonical 33 is GAME ON, derived from lower flipper reflex arming; aliases 34-36 are not additional outputs. The lower flipper 45-48 pair states are virtual mirrors, not added windings. The driver’s I/O exchange is 1000 Hz and stretches observed coil on-time to at least one frame for host visibility. Custom outputs 51-72 allocate from out-of-range firmware coil references in table traversal order; no exact custom mapping is asserted without the exact table.

The driver rewrites 101-108 from DIP bank 0 every millisecond. They are virtual readback mirrors, not writable substitutes for configuration ordinals 1-8. The lower EOS states are core-synthesized after CORE_FLIPSTROKETIME and direct writes are overwritten. Public nonzero is the subsystem's logical closed state; firmware wire-level flags remain separate. No `normally_closed` value or `initial_active` state is inferred. Current native library SHA256 is `8044e4dfbcd66dd2d686075f2b942d8c60c4a04899c603d2d67a9b2ff6103cd5`; it was used for the catalog export only, not a claimed game run.

The source declares one 16-character CORE_SEG16S layout at index 0, segment_start 0, with 256 modulated segments at levels 0-15. These are 16 character positions of one public layout, not sixteen physical display assemblies. ELG game test numbers count from 0 while public switch/coil/lamp references add 1. The source reads `g_smap*`, `__coil_table` and `__lamp_table` dynamically from the exact program; a source comment reporting a count cannot reproduce their semantic rows. CPU `g_smap_gpio` is empty for these ELG titles, so the common service/DIP converter does not establish a connected physical service panel. Source `avscp_103.manual.parts` is the home model’s own photographed Stern parts sheet, IPDB image 81401 courtesy of David Gray. Every ITEM/PART NUMBER/NAME row is transcribed, including the two distinct item 22 entries and the literal MEGATRON SWITCH ASSEMBLY name printed on this Avengers-labelled sheet. It establishes left/right flipper assemblies 500-6543-12-ND/500-6543-02-ND, in-line bank 500-1004-00, lock post 500-6752-04 and trough kicker 511-1013-00. These are useful physical assemblies, but no public switch, coil or LED reference appears in the table, so their structured mechanisms remain unbound. The parts table and a separately retained bottom-components drawing disagree on the trough assembly part; neither one is silently chosen.

The originals are retained at `working-root:manuals/by-machine/stern.avengers-the-pin.2013/ipdb-6373/`: image 10 is the quick setup sheet, image 11 owner instructions, image 12 bottom components/assemblies and image 13 top components/parts. The drawing’s callouts are assembly labels rather than calibrated physical measurements, so no coordinate is invented.
